# 남산장어 ver3 — 영상 페이지 초안

`index.html`을 더블클릭해 바로 실행할 수 있습니다. 로컬 서버 방식은 작업 폴더에서 `node site_ver.3/server.mjs`, 브라우저에서 http://127.0.0.1:4175 입니다.

- 파사드 → 입구 오브제 → 입구 어항 → 홀(왼쪽) → 홀(오른쪽) → 홀(중앙 · 자갈) → 조리대 간판. 각 사진에서 정지하며 HTML 설명을 표시합니다.
- 정지 구간: 1.7 화면 높이, 이동 구간: 1.65 화면 높이. `timeline.mjs`에서 조절합니다.
- ver1의 중앙 하단 배치, 그라데이션 상승 → 문구 페이드/80px 상승 순서를 적용했습니다.
- 마우스 휠 한 번으로 다음 사진 정지 지점까지 이동합니다. 위로 한 번 스크롤하면 이전 사진으로 돌아갑니다.
- 맨 앞은 공감 히어로(대표 문구 · 태그라인 "공사는 맡기시고, 사업 본질에 몰두하세요"). 히어로에서 휠을 내리면 투어 첫 장면으로, 첫 장면에서 올리면 히어로로 돌아갑니다.
- 마지막 사진(조리대 간판)에서 아래로 스크롤하면 투어가 끝나고 설득 섹션(`sections.css`)으로 이어집니다: 브릿지 → 01 돈 떼일까? → 02 바가지 쓸까? → 03 돈값을 할까? → 후기 → 상담(1단계 항목정리 비교 양식 · 2단계 무료 견적 미팅). 후기 전체는 `reviews.html`.
- 노란 점선 박스는 실제 자료(매출, 동선 도면, 후기, 상담 연결)를 넣을 자리입니다. `files/namsan-estimate.xlsx`는 site/dist 의 실제 항목정리 견적서 사본입니다.
- 공사일보(`#daily-report`)는 카카오톡 형태의 대화 예시입니다. `daily-report.css`와 `daily-report.js`에서 사진 확대·유지·복귀 → 세로 영상 확대·무음 재생·복귀를 제어합니다. 실제 자료는 `images/daily-report.png`, `files/daily-report.mp4`이며 원본은 상위 `asset` 폴더에 보존했습니다. 사진 클릭으로 원본을 열 수 있고 영상에는 재생·소리 컨트롤이 있습니다. 모션 축소 설정 또는 화면 높이 580px 미만에서는 고정 스크롤 연출 없이 수동으로 확인합니다.
- 모든 구간을 1.65배속으로 재생합니다. 1→2는 약 3.06초, 나머지 약 4.04초 영상은 각각 약 2.45초 동안 재생하고 앞뒤에 짧은 문구 전환 시간을 둡니다.
- 첫 영상은 기존 5.04초 파일, 나머지 영상은 약 4초 파일입니다.
- 3→4 초안은 Seedance 2.5, 480p, 무음으로 생성했습니다(작업 ID `d1d16021-d019-4a80-98b3-3a2dcfbece23`, 12크레딧). ver1/ver2 수정 없음.
- 4→5 초안은 Seedance 2.5, 480p, 무음으로 생성했습니다(작업 ID `c225fb4d-fcbd-42fa-a4d1-c556142ba4b4`, 사전 견적 12크레딧). 원본 재생 속도는 사이트에서 1.65배로 설정했습니다.
- 저해상도 초안 영상을 그대로 사용하므로 AI 영상 내부의 작은 글자 왜곡은 남아 있습니다. HTML 설명은 별도로 선명하게 표시됩니다.
- 데스크톱 우선. 모션 축소 설정에서는 사진으로 표시합니다.
