# 남산장어 · 사진 1→2 / 2→3 영상 초안

2026-10-01 요청: 두 이동 영상만 제작해 검토. 사이트 적용은 사용자 검토 이후.

- 제공 서비스: Higgsfield, 활성 Private 워크스페이스
- 모델: Seedance 2.0 Mini
- 설정: 480p, 16:9, 향후 생성분 각 4초, 오디오 생성 끔
- 시작/끝: 각 인접 사진을 start_image / end_image로 직접 지정
- 입력 준비: 원본 보존, 업로드용 1280×720 중앙 크롭 JPEG 별도 생성
- 4초 실제 입력 견적: 2크레딧/개. 기존 5초 견적은 2.5크레딧/개.
- 생성 전 잔액: 1,200크레딧
- 텍스트 오버레이는 향후 웹에서 별도로 구현

초안은 카메라 움직임과 두 사진 사이의 구조 일관성을 검토하기 위한 결과이다.
AI가 끝 프레임의 모든 픽셀이나 실제 공간 구조를 정확히 보존하는지는 출력 검토로 판단한다.
